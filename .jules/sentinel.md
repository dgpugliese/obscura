## 2026-06-14 - Remove dangerouslySetInnerHTML for QR Code

**Vulnerability:** The `src/app.jsx` component rendered QR code SVGs using `dangerouslySetInnerHTML`. The QR string content includes fragments of the current URL (the generated ciphertext download link). While the link was generally safe by design, relying on `dangerouslySetInnerHTML` combined with a string generated by an external library (`qrcode-generator`) creates an unnecessary risk if an attacker controls URL fragments or if the generation library has an escaping flaw.
**Learning:** `dangerouslySetInnerHTML` should be avoided whenever possible, especially for rendering SVGs that only represent geometric structures.
**Prevention:** It's safer to extract the matrix data from the QR library (`getModuleCount()`, `isDark(r, c)`) and render it natively with React SVG elements (`<svg>`, `<path>`) to ensure the DOM is constructed safely by React without any bypass logic.
