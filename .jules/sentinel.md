## 2025-02-14 - Fix DOM-based XSS in QR Code Component
**Vulnerability:** Found a Cross-Site Scripting (XSS) vulnerability related to rendering QR codes using `dangerouslySetInnerHTML`. The URL link that formed the QR Code payload wasn't fully sanitized and its associated `svg` generation was directly injected to the DOM instead of rendering the `img` tags over DataURLs.
**Learning:** Avoid `dangerouslySetInnerHTML` whenever possible, especially when the content involves components whose full string output might contain unintended execution payloads (like `onload` within tags generated by user input).
**Prevention:** Rather than directly embedding SVG strings as raw HTML into the DOM, use data URLs (e.g., `qr.createDataURL(5, 2)`) inside a standard `<img>` tag's `src` attribute. This guarantees no script execution because standard elements will process the DataURL securely as image output rather than executing inner text content.
